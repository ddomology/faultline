# Authentication bypass via OAuth implicit flow

## 문제 조건과 설명

**주어진 조건**

이메일 주소가 carlos@carlos-montoya.net인 Carlos 계정에 로그인한다.

**문제 설명**

OAuth 로그인 응답을 사용자 계정과 연결할 때 신뢰 경계를 확인하는 문제다.
