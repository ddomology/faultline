# Username enumeration via response timing

## 문제 조건과 설명

**주어진 조건**

로그인 응답 시간으로 사용자 이름을 구별할 수 있다. 자신의 계정은 `wiener:peter`이고 공식 문제에는 사용자 이름·비밀번호 후보 목록이 제공된다.

**완료 조건**

유효한 사용자 이름과 비밀번호를 찾아 그 계정 페이지에 접속한다.

**문제 설명**

응답 본문이 비슷하더라도 처리 시간 차이가 계정 정보를 드러낼 수 있는지 확인한다.

출처: [PortSwigger 실습 설명](https://portswigger.net/web-security/authentication/password-based/lab-username-enumeration-via-response-timing)

## 탐색 및 풀이 기록

아직 작성하지 않았다. 직접 확인한 요청·응답, 시도한 이유와 결과를 이 파일에 이어서 기록한다.
