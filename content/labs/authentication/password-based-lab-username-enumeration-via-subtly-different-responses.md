# Username enumeration via subtly different responses

## 문제 조건과 설명

**주어진 조건**

로그인 응답의 미세한 차이로 사용자 이름을 구별할 수 있고 비밀번호 무차별 대입에도 취약하다. 공식 문제에는 사용자 이름·비밀번호 후보 목록이 제공된다.

**완료 조건**

유효한 사용자 이름과 비밀번호를 찾아 그 계정 페이지에 접속한다.

**문제 설명**

눈에 잘 띄지 않는 응답 차이가 계정 존재 여부를 드러내는지 살펴본다.

## 탐색 및 풀이 기록

아직 작성하지 않았다. 직접 확인한 요청·응답, 시도한 이유와 결과를 이 파일에 이어서 기록한다.
