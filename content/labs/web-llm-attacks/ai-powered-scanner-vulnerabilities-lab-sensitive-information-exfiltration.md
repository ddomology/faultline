# Exploiting AI agents to exfiltrate sensitive information

## 문제 조건과 설명

**주어진 조건**

AI 스캐너가 API key 등 민감한 사용자 데이터에 접근하며 carlos의 로그인 정보도 갖고 있다. 개인 계정은 wiener:peter로 로그인하고 게시물에서 Scan site를 눌러 검사를 시작한다.

**완료 조건**

carlos의 API key를 외부로 유출해 제출한다.

**문제 설명**

사이트 감사 중 읽은 외부 콘텐츠가 스캐너의 비밀 데이터 처리에 영향을 주는지 살피는 문제다. 실시간 LLM의 응답은 달라질 수 있다.
