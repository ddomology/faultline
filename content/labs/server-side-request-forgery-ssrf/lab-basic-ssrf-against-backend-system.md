# Basic SSRF against another back-end system

## 문제 조건과 설명

**주어진 조건**

재고 확인 기능이 내부 시스템에서 데이터를 가져온다.

**완료 조건**

내부 `192.168.0.X` 범위의 8080 포트에서 관리 화면을 찾고 `carlos` 사용자를 삭제한다.

**문제 설명**

관리 화면의 정확한 내부 호스트 주소가 주어지지 않아 범위 안에서 확인해야 한다.

출처: [PortSwigger 실습 설명](https://portswigger.net/web-security/ssrf/lab-basic-ssrf-against-backend-system)

## 탐색 및 풀이 기록

아직 작성하지 않았다. 직접 확인한 요청·응답, 시도한 이유와 결과를 이 파일에 이어서 기록한다.
