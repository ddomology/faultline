# Basic SSRF against the local server

## 문제 조건과 설명

**주어진 조건**

재고 확인 기능이 내부 시스템에서 데이터를 가져온다.

**완료 조건**

재고 확인 URL로 `http://localhost/admin`의 관리 화면에 접근해 `carlos` 사용자를 삭제한다.

**문제 설명**

서버가 내부 주소를 대신 요청하는 SSRF 상황이다.
