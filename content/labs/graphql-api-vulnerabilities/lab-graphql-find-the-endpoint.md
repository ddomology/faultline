# Finding a hidden GraphQL endpoint

## 문제 조건과 설명

**주어진 조건**

사용자 관리 기능이 숨겨진 GraphQL 엔드포인트에 있으며 사이트를 클릭하는 것만으로는 찾을 수 없다. 엔드포인트에는 introspection 방어도 있다.

**완료 조건**

숨겨진 엔드포인트를 찾아 carlos를 삭제한다.

**문제 설명**

API 발견과 스키마 탐색의 제한을 구분해 확인하는 문제다.

출처: [PortSwigger 실습 설명](https://portswigger.net/web-security/graphql/lab-graphql-find-the-endpoint)

## 탐색 및 풀이 기록

아직 작성하지 않았다. 직접 확인한 요청·응답, 시도한 이유와 결과를 이 파일에 이어서 기록한다.
