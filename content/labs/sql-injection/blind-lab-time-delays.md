# Blind SQL injection with time delays

## 문제 조건과 설명

**주어진 조건**

추적 쿠키가 SQL 조회에 들어간다. 조회 결과, 행 반환 여부, 오류 여부가 응답에 드러나지 않지만 조회는 동기식으로 실행된다.

**완료 조건**

SQL 삽입으로 응답에 10초 지연을 발생시킨다.

**문제 설명**

화면 내용이 같아도 처리 시간의 차이는 관찰할 수 있다는 조건이 주어졌다.

출처: [PortSwigger 실습 설명](https://portswigger.net/web-security/sql-injection/blind/lab-time-delays)

## 탐색 및 풀이 기록

아직 작성하지 않았다. 직접 확인한 요청·응답, 시도한 이유와 결과를 이 파일에 이어서 기록한다.
