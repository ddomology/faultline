# Client-side desync

## 문제 조건과 설명

**주어진 조건**

서버가 일부 엔드포인트의 `Content-Length`를 무시해 클라이언트 측 동기화 오류에 취약하다.

**완료 조건**

피해자의 세션 쿠키를 얻어 그 계정에 접근한다.

**문제 설명**

브라우저가 보내는 연속 요청의 경계가 서버 해석과 어긋날 때 세션 정보가 노출될 수 있는지 확인한다.

출처: [PortSwigger 실습 설명](https://portswigger.net/web-security/request-smuggling/browser/client-side-desync/lab-client-side-desync)

## 탐색 및 풀이 기록

아직 작성하지 않았다. 직접 확인한 요청·응답, 시도한 이유와 결과를 이 파일에 이어서 기록한다.
