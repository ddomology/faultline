# Inconsistent security controls

## 문제 조건과 설명

**주어진 조건**

잘못된 권한 판정으로 일반 사용자도 회사 직원에게만 허용된 관리 기능에 접근할 수 있다.

**완료 조건**

관리자 패널에 접근해 carlos를 삭제한다.

**문제 설명**

직원 여부를 판단하는 규칙의 허점을 찾는 문제다.
