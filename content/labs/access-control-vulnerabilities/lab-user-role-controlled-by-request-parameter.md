# User role controlled by request parameter

## 문제 조건과 설명

**주어진 조건**

`/admin`은 위조 가능한 쿠키로 관리자를 식별한다. 제공된 일반 사용자 계정은 `wiener:peter`다.

**완료 조건**

관리자 패널에 접근해 `carlos` 사용자를 삭제한다.

**문제 설명**

클라이언트가 보낸 역할 표시만으로 관리자 권한을 판정하는 상황을 다룬다.
