# User role can be modified in user profile

## 문제 조건과 설명

**주어진 조건**

`/admin`은 로그인한 사용자 중 `roleid`가 `2`인 계정만 열 수 있다. 제공된 일반 사용자 계정은 `wiener:peter`다.

**완료 조건**

관리자 패널에 접근해 `carlos` 사용자를 삭제한다.

**문제 설명**

사용자 프로필의 역할 값 변경 가능성이 권한 판정에 영향을 주는지 살펴본다.
