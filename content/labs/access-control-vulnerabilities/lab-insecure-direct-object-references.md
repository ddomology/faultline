# Insecure direct object references

## 문제 조건

사용자 채팅 기록을 서버 파일 시스템에 저장하고 정적 URL로 제공한다.

## 완료 조건

`carlos`의 비밀번호를 찾아 그의 계정에 로그인한다.

## 문제 설명

정적 파일 경로가 다른 사용자의 기록을 보호하는지 확인하는 문제다.
