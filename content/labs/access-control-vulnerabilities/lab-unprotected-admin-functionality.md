# Unprotected admin functionality

## 문제 조건과 설명

**주어진 조건**

관리자 패널에 접근 제한이 없다.

**완료 조건**

관리자 기능으로 `carlos` 사용자를 삭제한다.

**문제 설명**

관리자 전용이어야 할 기능의 접근 제어가 적용되는지 확인하는 문제다.
