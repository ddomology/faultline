# User ID controlled by request parameter with data leakage in redirect

## 문제 조건과 설명

**주어진 조건**

리디렉션 응답 본문에 민감한 정보가 새어 나오는 접근 제어 취약점이 있다. 제공된 계정은 `wiener:peter`다.

**완료 조건**

`carlos`의 API 키를 얻어 제출한다.

**문제 설명**

최종 이동 화면뿐 아니라 중간 HTTP 응답에도 정보가 남는지 살펴본다.
