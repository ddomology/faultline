# Multi-step process with no access control on one step

## 문제 조건과 설명

**주어진 조건**

사용자 역할을 바꾸는 관리자 기능이 여러 단계로 이루어져 있으며 한 단계의 접근 제어에 결함이 있다. 관리자 계정은 `administrator:admin`, 일반 계정은 `wiener:peter`다.

**완료 조건**

`wiener`로 로그인해 자신의 권한을 관리자로 높인다.

**문제 설명**

여러 단계 중 각 요청마다 권한 검사가 이루어지는지 살펴본다.

출처: [PortSwigger 실습 설명](https://portswigger.net/web-security/access-control/lab-multi-step-process-with-no-access-control-on-one-step)

## 탐색 및 풀이 기록

아직 작성하지 않았다. 직접 확인한 요청·응답, 시도한 이유와 결과를 이 파일에 이어서 기록한다.
