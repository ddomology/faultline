# Scanning non-standard data structures

## 문제 조건과 설명

**주어진 조건**

수동으로 찾기 어려운 취약점이 비표준 데이터 구조 안에 있다. 개인 계정은 wiener:peter로 로그인한다.

**완료 조건**

Burp Scanner의 Scan selected insertion point로 취약점을 찾아 수동으로 악용하고 carlos를 삭제한다.

**문제 설명**

일반 매개변수 밖에 있는 삽입 지점을 식별하는 문제다.
