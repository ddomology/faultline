# File path traversal, traversal sequences stripped non-recursively

## 문제 조건과 설명

**주어진 조건**

상품 이미지의 파일 이름에서 경로 탐색 문자열을 제거한 뒤 사용한다. 이 제거 과정은 재귀적으로 반복되지 않는다.

**완료 조건**

`/etc/passwd` 파일 내용을 읽는다.

**문제 설명**

문자열 제거 이후 남은 경로가 어떻게 해석되는지 살펴보는 문제다.

출처: [PortSwigger 실습 설명](https://portswigger.net/web-security/file-path-traversal/lab-sequences-stripped-non-recursively)

## 탐색 및 풀이 기록

아직 작성하지 않았다. 직접 확인한 요청·응답, 시도한 이유와 결과를 이 파일에 이어서 기록한다.
