# DOM-based cookie manipulation

## 문제 조건과 설명

**주어진 조건**

클라이언트 측 DOM 처리로 쿠키가 조작될 수 있다.

**완료 조건**

다른 페이지에서 XSS가 발생하는 쿠키를 주입해 `print()`를 호출한다. exploit server로 피해자를 필요한 페이지에 유도해야 한다.

**문제 설명**

쿠키 설정 지점과 XSS 실행 페이지가 서로 다르다는 조건이 있다.
