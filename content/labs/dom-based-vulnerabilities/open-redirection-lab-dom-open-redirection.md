# DOM-based open redirection

## 문제 조건

사이트에 DOM 기반 열린 리디렉션 취약점이 있다.

## 완료 조건

피해자를 exploit server로 리디렉션한다.

## 문제 설명

브라우저 측 URL 처리로 이동 대상이 바뀌는지를 확인하는 문제다.
