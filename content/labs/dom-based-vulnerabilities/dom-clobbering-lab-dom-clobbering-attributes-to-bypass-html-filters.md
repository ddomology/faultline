# Clobbering DOM attributes to bypass HTML filters

## 문제 조건과 설명

**주어진 조건**

HTMLJanitor 라이브러리에 DOM clobbering 취약점이 있다. 의도된 방식은 Firefox에서 작동하지 않아 Chrome 사용이 권장된다.

**완료 조건**

필터를 통과하는 입력으로 DOM clobbering을 일으켜 `print()` 함수를 호출한다.

**문제 설명**

피해자 브라우저에서 자동 실행되게 하려면 exploit server가 필요할 수 있다.
