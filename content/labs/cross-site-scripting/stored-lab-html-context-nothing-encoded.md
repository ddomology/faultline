# Stored XSS into HTML context with nothing encoded

## 문제 조건과 설명

**주어진 조건**

댓글 기능에 저장형 XSS 취약점이 있다.

**완료 조건**

댓글을 제출하고 블로그 글을 볼 때 `alert` 함수가 호출되게 한다.

**문제 설명**

댓글 내용이 저장되었다가 다른 페이지 조회 시 다시 표시되는 흐름이다.

출처: [PortSwigger 실습 설명](https://portswigger.net/web-security/cross-site-scripting/stored/lab-html-context-nothing-encoded)

## 탐색 및 풀이 기록

아직 작성하지 않았다. 직접 확인한 요청·응답, 시도한 이유와 결과를 이 파일에 이어서 기록한다.
