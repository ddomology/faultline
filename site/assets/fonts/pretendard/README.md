# Pretendard Variable 1.3.9

Unmodified variable WOFF2 from the official Pretendard v1.3.9 tag.

- Font size: 2,057,688 bytes
- SHA-256: `9599f12fd42fc0bce1cd50b47a0c022e108d7aa64dd0d1bb0ed44f3282d900b4`

The build copies this directory to `static/fonts/pretendard/` on the site.
`site/reader.scss` defines a locally served font face with weights 100–900 and
`font-display: swap`. Interface, titles, and body text share this family;
code and note numbering retain the existing monospace family.

The font binary has not been subsetted, renamed, or otherwise modified.
